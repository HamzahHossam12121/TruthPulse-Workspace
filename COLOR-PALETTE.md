# TruthPulse color palette

The UI uses a trust-and-verification palette:

- Deep ink navy `#0b1220`: primary dark surfaces and headings.
- Electric blue `#2563eb`: primary actions and links.
- Cyan `#06b6d4`: AI accents and focus highlights.
- Pale cyan `#a5f3fc`: soft highlight on dark surfaces.
- Cool near-white `#f5f8fc`: page background.
- Slate `#64748b`: secondary text.
- Red `#dc2626`: validation and error states only.

The aim is to feel analytical, modern, and trustworthy without the previous red/black/sage mix. AI results should use explicit labels (for example, likely authentic, suspicious, or inconclusive) rather than relying on color alone.
